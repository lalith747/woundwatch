## 🧠 The Intelligence Engine

The `PrototypeObservationEngine` runs **entirely in the browser**. Here's what it actually does:

### 1. Visual Signal Extraction
```typescript
// Canvas-based color analysis — no external API
const extractVisualSignal = (imageData: ImageData): VisualSignal => {
  // Scan pixel-by-pixel within the user-defined wound region
  // Extract red channel dominance (wound color proxy)
  // Compute observable area (non-background pixel count)
  // Return normalized 0-100 signal scores
};
```

### 2. Vector Normalization
All four dimensions are independently normalized to **0–100**:

```
Pain Score    = (rawPain / 10) × 100
Visual Score  = regionRedDominance           (already 0–100 from CV)  
Area Score    = min(100, (observableArea / 1250) × 100)
Symptom Score = min(100, symptomCount × 25)
```

### 3. Multivariate Anomaly Detection
```typescript
// Euclidean distance in normalized 4D space
const distance = Math.sqrt(
  (current.pain    - baseline.pain)²    +
  (current.visual  - baseline.visual)²  +
  (current.area    - baseline.area)²    +
  (current.symptoms - baseline.symptoms)²
);

// Flag anomaly if distance > 2σ of historical distances
if (distance > mean + 2 * stdDev) flagAnomaly(current, evidence);
```

### 4. Change-Point Detection
```typescript
// Compare current derivative to rolling average derivative
const currentDelta   = vectorDistance(current, previous);
const averageDelta   = mean(historicalDeltas);

// Spike = sudden acceleration in any direction
if (currentDelta > averageDelta * SPIKE_THRESHOLD) {
  flagChangePoint({ day: current.day, magnitude: currentDelta });
}
```

### 5. Observation Confidence Scoring
```
Confidence = weighted average of:
  - Image quality score      (35%)
  - History length bonus     (30%)
  - Region consistency       (20%)
  - Symptom data completeness (15%)
```
